# Project Status

The [architecture specification](architecture-v0.1.md) defines the execution model, timing contract, and energy measurements for the first implementation milestone.

Open decisions include the physical reference platforms for AArch64 and x86-64, the method for deriving worst-case execution-time bounds, and the formal verification tool.

Once the first runnable workload is available, the [README](../README.md) will list its prerequisites, run command, and expected output.
